# 研究未识别服务通用指纹增强

## Goal

评估对 `unknown`、`tcpwrapped` 和空服务名进行二次识别的安全、有效方案，在实施前定义流量预算、证据和误报契约。

## Requirements

- 比较 Nmap 探针增强、协议专用轻量探针、httpx、Nuclei network/http tags 及其他可行方案。
- 不把 Dameng 定向握手探针直接推广为所有协议的通用实现。
- 明确候选端口选择、协议猜测、并发、单端口请求上限、超时、重试和全 Run 预算。
- 明确哪些探测需要额外授权，排除爆破、破坏性或高负载行为。
- 定义“已识别”的最小证据、置信度、冲突处理、误报回退和 provenance。
- 评估 `tcpwrapped` 是否适合主动重探；不能假定它等同于普通 unknown。
- 产出推荐方案、拒绝方案及一个可控 MVP 的后续实施任务建议；本任务不修改扫描管线。

## Non-goals

- 不对所有未知端口无差别运行宽泛 Nuclei tags。
- 不在研究阶段新增网络探测代码。
- 不覆盖已有的 Dameng 专用协议识别修复。

## Acceptance Criteria

- [ ] 研究文档给出候选方案的正确性、安全性、覆盖率、维护成本和运行成本比较。
- [ ] 推荐方案包含明确的请求预算、超时、授权和停止条件。
- [ ] 定义可测试的证据、置信度、误报和冲突契约。
- [ ] 至少用代表性的 unknown、tcpwrapped、空服务名和已知服务样本验证假设，或记录无法验证的环境限制。
- [ ] 只有证据支持时才提出实施任务；否则明确建议不实现。
