# 统一 Web Console 上海时区显示

## Goal

让扫描详情和单工具实时 Console 以一致、明确的上海时间显示事件，同时保持存储和 API 的 UTC 契约。

## Requirements

- 所有 Web Console 事件时间固定显示为 `Asia/Shanghai`。
- 显示格式为 `YYYY-MM-DD HH:mm:ss.SSS UTC+8`。
- 扫描详情与单工具实时输出复用同一格式化契约。
- 数据库继续存储 UTC，API 继续返回 RFC3339 时间。
- 格式化不得改变事件排序、增量轮询、事件 ID 或原始时间值。
- 无效时间不得导致页面崩溃，应采用明确的回退显示。

## Non-goals

- 不迁移或改写历史数据库时间。
- 不增加用户可配置时区。
- 不改变 CLI 日志时间契约，除非后续另有需求。

## Acceptance Criteria

- [ ] UTC 示例 `2026-07-29T07:18:40.714Z` 在两个 Web Console 中均显示为 `2026-07-29 15:18:40.714 UTC+8`。
- [ ] 数据库存储与 API 响应仍保持 UTC/RFC3339。
- [ ] 扫描详情和单工具 Console 使用相同格式化实现和输出格式。
- [ ] 毫秒补零、跨日转换及无效输入有确定性测试。
- [ ] 事件轮询和排序行为无回归。
