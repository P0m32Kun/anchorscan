# 增强报告服务筛选与未识别服务排除

## Goal

让用户在保留完整扫描事实的前提下，快速看见已识别服务，并避免大量 `tcpwrapped` 记录淹没有效结果。

## Requirements

- 报告默认继续展示全部指纹，不默认隐藏任何开放端口。
- 服务筛选器展示当前 Run 的服务名称及数量。
- 提供“一键排除未识别服务”，其原始值集合为 `tcpwrapped`、`unknown` 和空服务名。
- “未识别”仅是展示与查询快捷分组，不得修改持久化的原始服务名。
- 服务数量应用其他报告筛选条件，但不应用当前服务筛选，避免选项自我消失。
- 保留现有单个服务名的正向精确筛选能力。
- 改变筛选条件后，资产和 Finding 分页均回到第一页。
- HTML 页面与现有导出入口采用一致的筛选语义。
- 空服务名必须以可理解的标签呈现，不显示为空白选项。

## Non-goals

- 不删除或重写 `tcpwrapped` 指纹。
- 不引入用户偏好持久化。
- 不在本任务中增强服务识别能力。
- 不新增独立 facets API，除非实现证据证明现有报告 Handler 无法安全提供数据。

## Acceptance Criteria

- [x] 默认打开报告时，全部原始指纹仍然可见。
- [x] 服务筛选器展示稳定排序的服务类型及准确数量。
- [x] 用户可一次排除 `tcpwrapped`、`unknown` 和空服务名，并可清除该筛选。
- [x] 选择或清除筛选后，两类分页均从第一页开始且保留其他查询条件。
- [x] 选择一个服务后，其他服务选项及数量不会消失。
- [x] 筛选后的 HTML 与导出结果使用相同的 include/exclude 语义。
- [x] 后端筛选/聚合、查询参数和前端交互均有自动化测试。
